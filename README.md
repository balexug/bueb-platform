# bueb-platform
BÜB Assist: Digitale Baustellendokumentation &amp; Mängelmanagement für die Bahn. Monorepo mit Flutter App (Offline-First, BTB, Sprachnotizen, KI-Suche) und React Admin-Panel. Rollenbasierte Plattform für BÜB, FBÜ &amp; Selbstständige. Mobile All-in-one-Plattform mit KI-Fachassistent mit Quellenangabe. Inkl. Web-Admin-Panel.
